What to look for

  • Dev server, restarting. A service on this PC that stops for 20 seconds every 75: it goes down, the table says so, and it comes back.
  • Redis, not running. Nothing listens on port 6379, so the connection is refused at once. The PC is up; the service is not.
  • amazon.com. Ignores ping but answers on port 443. Ping alone would call the site down.
  • example.com:22. No answer at all: a firewall drops it, which is not the same as a refusal.
  • Old printer. Switched off. The network reports it unreachable, or nothing comes back at all.
  • Far away. Australia, New Zealand, Uruguay and Europe at 160 to 200 ms. That is distance, not trouble.

What it does

One table

Every host on one screen: state, last and average round trip, a trend of the last 60 pings, loss, IP address and name.

Monitor a TCP service

Add a service such as example.com:443 to watch its availability, latency and loss alongside the hosts you ping.

Add hosts fast

Type a host, choose ping or ports, press Enter. Paste a list. Import a CSV file from another ping tool, or drop it on the window.

Act on a selection

Click, Ctrl-click or Shift-click rows, then right-click: mute, ping now, ping only these, measure, trace the route, reset counters.

Copy as text, Markdown, JSON or TSV

Right-click a host, a group or the whole table: text for a chat or a ticket, Markdown for GitHub or a wiki, JSON for a program or an AI agent, TSV for a spreadsheet.

Measure

Ping chosen hosts up to ten times a second for a set time and get loss, median, 95th percentile and jitter.

Trace route

See the routers between you and a host, with names, in about a second.

Alerts

A host is down after a number of failed pings you choose. Get a notice, a sound, or run your own command.

Works with AI agents

A built-in MCP server gives any agent, hosted or local, tools to ping, trace routes and read the running table. Scripts get a command line and a local API.

From the command line

The zip also holds pingtable-cli.exe: the same program without the window. Use it for one quick answer, in a script, or in a scheduled task. It needs no administrator rights.

> pingtable-cli once 192.168.1.1 example.com:443
HOST         CHECK    STATE  TIME ms
192.168.1.1  icmp     UP        0.41
example.com  tcp:443  UP       12.80

Reading a TCP result

  • OK. The service accepted the TCP connection.
  • Connection refused. The host rejected the connection.
  • Timed out. The service did not answer within the configured timeout.
  • Nothing is sent. The connection is closed the moment it opens.

How it is built

  • One small program. Written in Rust and compiled to a native Windows program. Nothing else to install.
  • No administrator rights. It pings through the same Windows service the built-in ping command uses, and runs from any folder you can write to.
  • Stays on your machine. No telemetry, no account, no update check. It talks only to the hosts on your list.
  • Light and dark. One switch.

Download

  1. Choose the native window or browser ZIP from the latest release.
  2. Unpack it in a folder only your account can change.
  3. Double-click pingtable.exe for the native window or pingtable-cli.exe for the browser table.

The release notes list each ZIP’s SHA-256 checksum and the programs’ signing status. Windows may show an “unknown publisher” warning for unsigned programs.
