WHAT IT DOES

One table

Every host on one screen: state, last and average round trip, a trend of the last 60 pings, loss, IP address and name.

ICMP and TCP

Ping by ICMP over IPv4 and IPv6, or check that a TCP port answers. Ranges and CIDR blocks expand into hosts.

Add hosts fast

Type a host and a description and press Enter. Paste a list. Drop a CSV file from another ping tool onto the window.

Act on a selection

Right-click one host or many: mute, ping now, ping only these, measure, trace the route, copy a summary.

Measure

Ping chosen hosts up to ten times a second for a set time and get loss, median, 95th percentile and jitter.

Trace route

See the routers between you and a host, with names, in about a second.

Alerts

A host is down after a number of failed pings you choose. Get a notice, a sound, or run your own command.

Yours to script

Everything the window does goes through a small local API, so a script can do it too.

HOW IT IS BUILT

  • One small program. Written in Rust and compiled to a native Windows program. Nothing else to install.
  • No administrator rights. It pings through the same Windows service the built-in ping command uses, and runs from any folder you can write to.
  • Stays on your machine. No telemetry, no account, no update check. It talks only to the hosts on your list.
  • Light and dark. One switch.

DOWNLOAD
