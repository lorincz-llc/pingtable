    Options, after a host or a group

    every=5s
    its own interval
    timeout=300ms
    its own timeout
    tag=lan
    a tag you can filter on

    Shape the ping packet

    size=1400
    payload bytes
    ttl=8
    hop limit
    df=on
    do not fragment
    dscp=46
    traffic marking
    data=hello
    payload contents, or 0xBEEF

    SETTINGS

    A host can have its own interval and timeout: add every=5s or timeout=300ms after it in the host list.

    Variables: %HostName% %IPAddress% %Description% %Group% %Status% %SucceedCount% %FailedCount% %ConsecutiveFailedCount% %LastPingTime%. The same values are passed as PINGTABLE_ environment variables.

    ADD HOSTS

    A host name or address, then an optional description. One per line for several. Enter adds; Shift+Enter starts a new line.
